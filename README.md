# 24点挑战（Point-24 Game）

一个纯前端、零依赖、离线可玩的 24 点益智小游戏 —— 单个 HTML 文件，双击即玩，也可以在线玩（见下方链接）。

## 在线试玩

开启 GitHub Pages 后访问：`https://<你的用户名>.github.io/point24-game/`（见仓库设置或 README 顶部链接）

## 玩法

每题发 4 张牌（A=1, J=11, Q=12, K=13），用 `+ − × ÷` 把牌面算成 **24**，每张牌用且只用一次。

## 特性

- **两种规则**：整数模式（默认，除法必须整除、所有中间结果均为整数）/ 经典模式（允许分数中间值，如名题 3 3 8 8 → 8÷(3-8÷3)）
- **三档难度**：简单 90s ×1.0 / 普通 60s ×1.3 / 困难 45s ×2.0，按解法数量自动调控发牌
- **多解分析**：每题枚举全部「本质不同」的解法，自动标注特点、优缺点并给出推荐解
- **精确分数运算**：内置 gcd 约分的有理数运算，杜绝浮点误差；自研表达式解析器，不使用 eval
- **暂停/继续**：随时暂停（P 键），倒计时冻结，恢复后无缝继续
- **答题回顾**：每题结束后自动归档题号、牌面、判定、得分、我的答案与参考解
- **结束不清屏**：胜负结算后保留画面与回顾区，点「结束」才返回主页
- **完整交互**：鼠标/触屏点选 + 键盘（1-4 选牌、+ − * / 运算、退格撤销、P 暂停、H 提示、S 跳过、Esc 重置）
- **响应式 + 音效**：适配手机；WebAudio 现场合成音效，无需加载任何资源文件

## 运行

无需安装任何东西：

- 直接双击 `index.html` 在浏览器打开；或
- `python -m http.server` 后访问 `http://localhost:8000`

## 质量验证

求解器经过全量自检：1-13 四张牌共 1820 种组合、4469 条解，每条解均被独立解析器复算为 24 且用牌一致；有解组合 1362 组，与经典数学结论一致。
